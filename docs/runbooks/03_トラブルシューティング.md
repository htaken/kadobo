---

## 症状 1: ボタンを押してもカードが変わらない／`⚠️ 記録待ち`のまま

1. **転送フラグ**を確認（[02] C）。`0` なら `1` に戻す。
2. **pending の滞留**を確認:
   ```
   ! cd /Users/takenouchiharuhi/projects/kadobo/worker && npx wrangler d1 execute DB --remote --command "SELECT status, COUNT(*) FROM journal GROUP BY status"
   ```
   pending が多い → GAS 転送が失敗している。
3. **最新の last_error** を確認:
   ```
   ! cd /Users/takenouchiharuhi/projects/kadobo/worker && npx wrangler d1 execute DB --remote --command "SELECT kind, attempts, last_error, updated_at FROM journal WHERE status='pending' ORDER BY updated_at DESC LIMIT 5"
   ```
   - `last_error=timeout` / `http_500` → GAS 側の実行時例外。GAS 実行ログを確認
   - `last_error=UNAUTHORIZED` → 封筒検証失敗＝`GAS_SHARED_SECRET` が Worker と GAS で不一致（下記 症状 4）
   - `last_error=http_401` → `GAS_URL` が違う／GAS がウェブアプリとして公開されていない
   - `last_error=invalid_response_shape` / `non_json_response` → GAS が HTML（認可エラー画面等）を返している。デプロイのアクセス設定＝「全員」を確認
4. 原因を直せば、5 分周期の Cron が自動再送して `✅` になる（押し直し不要）。

---

## 症状 2: Slack が「dispatch_failed」等、コマンド自体が失敗

- Worker が 3 秒以内に応答できていない、または Request URL が誤り。
- Slash Command / Interactivity の Request URL が `WORKER_URL/slack/commands`・`/slack/interactivity` になっているか確認（[01] ④）。
- `npx wrangler tail` で 401 が出ていれば署名検証失敗 → `SLACK_SIGNING_SECRET` を確認（症状 3）。

---

## 症状 3: 全リクエストが 401（Worker ログに signature verification failed）

- `SLACK_SIGNING_SECRET`（Worker secret）が Slack の Basic Information の Signing Secret と一致しているか。
  ```
  cd /Users/takenouchiharuhi/projects/kadobo/worker && npx wrangler secret put SLACK_SIGNING_SECRET   # 正しい値で上書き
  ```
- サーバ時刻ズレで timestamp 窓（±5 分）を外していないか（通常は問題にならない）。

---

## 症状 4: GAS が常に UNAUTHORIZED を返す（封筒検証失敗）

- `GAS_SHARED_SECRET` が **Worker secret** と **GAS Script Property** で完全一致しているか。
  片方を変えたら両方変える。安全のため [02] B の停止フラグを使って更新 → 再開。
- 一致確認のため、まず [01] ⑤-8 の HMAC 実地確認をやり直す。

---

## 症状 5: 打刻の時刻がずれる／業務日がおかしい

- 打刻時刻は Slack の `action_ts`（押下瞬間）を採用しているので、再送・遅延でズレないのが仕様。
- 跨日（0 時またぎ）は**開始日**に帰属する（暫定仕様。要件 §7 で A 社と確定）。
- GAS プロジェクトのタイムゾーンが `Asia/Tokyo`（`appsscript.json`）であることを確認。

---

## 症状 6: 日次が「要修正」になる

- `START` に対応する `END` が無い等ペアリング不能。修正モーダル（✏️ 修正）で不足イベントを追加／時刻修正する。
- 「終了イベントを追加（押し忘れ）」は稼働中／休憩中のときのみ選べる。

---

## 症状 7: Cron が動いていない気がする

- Cron は `*/5 * * * *`（再送）と `17 3 * * *`（クリーンアップ）。Cloudflare ダッシュボード → Worker → Triggers で登録を確認。
- Free プランでも Cron Triggers は利用可。実行状況は `npx wrangler tail` で scheduled イベントを観測。

---

## 症状 8: `clasp push` が失敗する

- `gas/.clasp.json` の `scriptId` と `rootDir: "dist"` を確認。
- 先に `npm run build` で `gas/dist/Code.js` を生成しているか。
- `npx clasp login` の認証が切れていないか。
